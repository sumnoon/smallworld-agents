About this mode

Offline demo mode uses rules and a small set of supported requests. Live mode uses generated dialogue and decisions.

Local live mode uses Ollama and the model shown below the town. Keep Ollama running. Configure AGENT_PROVIDER=ollama and AGENT_MODEL in the server's .env, then restart. Ollama needs no cloud API key.
